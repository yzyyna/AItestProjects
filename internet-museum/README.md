# 《404 之前：互联网考古馆》· 穿越 1998~2099 的数字文明档案

> 纯 **HTML5 + CSS3 + 原生 JavaScript** 架构的沉浸式沉浸年代体验展馆。
> 零构建依赖、零外部打包库，跨越近半个世纪的互联网文化演进与未来想象，双击 `index.html` 离线即开即赏。

---

## 🏛️ 展馆年代概览

展馆由 6 大主题年代展厅组成，真实还原不同时期的界面风格与人机交互质感：

1. **1998 · 拨号接入室**：56K Modem 尖锐刺耳的握手拨号音、绿色荧光单色 CRT 终端、纯文本 BBS 留言板。
2. **2003 · 闪光与桌面时代**：Macromedia Flash 矢量动画、拟态立体水滴水晶 UI、古早个人主页与计数器。
3. **2008 · Web 2.0 繁荣前夜**：Blog 博客大潮、社交网络早期形态、渐变色圆角与 RSS 订阅流。
4. **2012 · 移动浪潮与扁平化破晓**：拟物化（Skeuomorphism）向扁平化（Flat Design）演变、早期的响应式排版与瀑布流。
5. **2024 · 算法巨浪与生成式智能**：无限瀑布流 Feed、信息茧房感知器、AI 大模型实时协作生成界面。
6. **2099 · 赛博遗迹与深空漫游**：全息交互、量子纠缠信道与未来数字考古档案馆。

---

## 🌟 核心技术亮点

- **模块化纯原生架构**：按年代独立组织 ES 模块（`js/eras/era-*.js`），解耦良好，无框架依赖。
- **年代感音效合成与还原**：基于 Web Audio API 算法合成 1998 经典拨号连接握手声、旧式键盘敲击声等。
- **时代特色 CSS 视觉还原**：像素点阵字体、CRT 扫描线着色器式滤镜、拟态阴影与玻璃态样式无缝切换。
- **彩蛋系统**：内置年代彩蛋（Konami 秘籍、复古彩蛋等），增强互动沉浸感。
